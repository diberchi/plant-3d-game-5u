# 國小五上自然科學 第二單元「千變萬化的植物」3D 沉浸式教學遊戲
## 專案說明與操作指南

### 1. 專案簡介
本專案為依據**台灣 108 課綱五上自然科學第二單元「千變萬化的植物」**所設計之 3D 沉浸式網頁闖關遊戲。
以 HTML5 + WebGL (Three.js) + WebAudio 打造，單一 HTML 檔案架構，可直接點擊在任何現代瀏覽器（Chrome、Edge、Safari、Firefox）離線/線上執行，亦可無縫部署於 GitHub Pages 或一般靜態網站主機。

- **教材對應**：翰林版五上自然課本（第 40~69 頁）、115-1 官方段考及單元評量卷
- **適用對象**：國小五年級學生、自然科教師、自學家庭
- **核心能力**：PIRLS 閱讀理解四層次（擷取訊息、直接推論、詮釋整合、評鑑）與科學探究實作

---

### 2. 檔案清單
- **`index.html` / `game.html`**：線上版 3D 教學遊戲主程式（支援電腦 WASD/滑鼠視角與手機/平板觸控搖桿）。
- **`關卡與題目腳本.md`**：全遊戲 4 幕 11 關 28 道素養題之題型、題目、選項、詳解與課文對照。
- **`README.md`**：本專案說明文件。

---

### 3. 操作方式
#### 電腦版：
- **移動**：鍵盤 `W`, `A`, `S`, `D` 或 方向鍵 `↑`, `←`, `↓`, `→`
- **旋轉視角**：在 3D 畫面上按住滑鼠左鍵拖曳
- **互動/對話**：靠近目標植物或光圈時，點擊右下角「🔍 探索 / 接受挑戰」按鈕或空白鍵
- **選單功能**：右上角提供「📖 關卡一覽」、「💾 儲存進度」、「🔊 音效開關」、「🎓 教師通道」

#### 手機 / 平板（iPad）版：
- **移動**：畫面左下方自動呼叫「虛擬類比搖桿」，滑動即可控制角色前進方向與速度
- **視角**：畫面右半部滑動旋轉環顧四周
- **互動**：直接點擊畫面上的大按鈕進行課文閱讀與闖關

#### 教師專屬通道：
- 點擊右上角「教師通道」或按鈕，輸入通行碼 **`teacher115`** 或 **`ijun`**，即可一鍵解鎖全部 11 個關卡，方便課堂分段教學與示範！

### 4. 關卡與主題規劃
1. **第一幕：植物身體的秘密（根、莖、葉）**
   - 關卡 01：深藏不露的根部密碼（軸根、鬚根、氣生根、板根、儲藏根）
   - 關卡 02：挺拔的莖與水分高速公路（草本/木本莖、維管束紅水輸送路徑）
   - 關卡 03：神奇的綠色工廠——葉片探秘（葉脈、夾鏈袋葉面蒸散、氣孔光合作用）
2. **第二幕：花、果實與授粉的奇蹟**
   - 關卡 04：花朵的微觀世界（花萼、花瓣、雄蕊花藥、雌蕊柱頭子房胚珠）
   - 關卡 05：生命轉化的奇蹟（蟲媒傳粉、受精、子房成果、胚珠成種）
3. **第三幕：植物種子大冒險（四大傳播方式）**
   - 關卡 06：乘風飛翔的精靈（風力傳播：蒲公英冠毛、木棉棉毛、青楓薄翅）
   - 關卡 07：動物是我的特快車（動物傳播：大花咸豐草倒鉤、鳥類食用排泄）
   - 關卡 08：自身彈射與乘風破浪（彈力傳播：鳳仙花/酢漿草；水力傳播：椰子浮力）
4. **第四幕：環境適應與植物分類二分法**
   - 關卡 09：適者生存的綠色智慧（高山玉山圓柏抗風、沙漠仙人掌刺針耐旱）
   - 關卡 10：植物特徵二分法大挑戰（科學客觀二分法分類）
5. **終章：榮譽特優證書結算盛典**
   - 關卡 11：輸入學員姓名與學校，即時 Canvas 渲染高解析榮譽證書並支援圖檔下載！
